# Nested Structure with User Input

## Author
M.Likitha

## Description
This program demonstrates a nested structure where the
Employee structure contains a Date structure.

The program accepts employee information and joining date
from the user and displays the stored details.

## Concepts Used
- Structure
- Nested structure
- User input
- scanf()
- Nested structure member access
- Structure initialization through input

## How to Run

gcc nested_structure_input.c -o nested_structure_input

./nested_structure_input

## Sample Output

Enter employee ID: 205
Enter employee name: Ravi
Enter joining date (DD MM YYYY): 15 8 2026

Employee Details
ID: 205
Name: Ravi
Joining Date: 15-08-2026
